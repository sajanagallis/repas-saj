BASE DE PRÉ-REMPLISSAGE

Semaine habituelle

Cette semaine type sert uniquement à préremplir les nouvelles semaines. Une commande de semaine déjà créée n’est jamais modifiée lorsque vous changez la Semaine habituelle.

Important : les semaines déjà créées conservent leurs choix. Pour recommencer volontairement une semaine depuis ce modèle, utilisez « Réinitialiser depuis la semaine habituelle » dans la commande avancée.

Historique des commandes

Seules les semaines terminées apparaissent ici. Cliquez sur une semaine pour l'ouvrir dans le widget.

Personnes et présences habituelles

Le type de pain habituel est utilisé automatiquement pour les pique-niques. Désactiver une personne conserve toutes les anciennes commandes.

Fermetures de l’établissement

Ces fermetures rendent automatiquement toutes les personnes absentes et verrouillent le jour concerné. Les vacances scolaires affichées dans le widget restent uniquement indicatives.

Jours fériés

Un jour férié est fermé par défaut. Cochez uniquement un jour où l’établissement sera exceptionnellement ouvert.

Calendrier scolaire — Académie de Lyon

Information uniquement : les vacances scolaires ne ferment pas l’établissement et ne modifient aucune commande. Les années scolaires sont isolées dans un bloc de données dédié du script pour être ajoutées sans modifier le moteur du widget.
