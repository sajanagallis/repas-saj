Outlook et traçabilité

Sans URL Power Automate, le widget télécharge le PDF puis ouvre Outlook avec l'adresse, l'objet et le message préremplis. Une pièce jointe automatique nécessite le flux Power Automate décrit dans POWER_AUTOMATE.md.

Aide rapide

Semaine modèle : chaque nouvelle semaine est créée à partir de la semaine modèle. Une fois créée, elle devient indépendante et peut être modifiée sans changer le modèle ni les autres semaines.

Semaines futures : le widget crée automatiquement un horizon de 8 semaines à partir de cette semaine modèle.

Plateau / container / pique-nique : choisir le type directement dans la case du jour. Pour un même jour, une personne ne peut être comptée qu'une fois : soit sur son étage, soit en plateau/container/pique-nique. Les blocs spéciaux n'apparaissent à l'impression que s'il y en a.

Contrôle : « Vérifier la commande » recherche les repas incohérents, les retraits sans heure et les doublons avant l'envoi.

Rectificatif : toute modification après une commande déjà marquée « Commandée » est signalée comme rectificative.

Vacances : les jours fermés sont mis à zéro et portent la mention FERMÉ. La commande reste imprimable.

Impression : page 1 = récapitulatif A4 portrait ; page 2 = détail A4 paysage. Le détail adapte sa densité au nombre de personnes.
